Each app has its own environment variables and secrets, managed on the project's
**Secrets** page.

## Adding a variable

Add a key and value; mark it **secret** to mask it in the dashboard. Keys must be
letters, digits and underscores, starting with a letter or underscore.

<Callout>
  Values are injected into the app's container **at build time**. A variable you
  add is stored immediately but only goes live on the **next deploy** — the page
  flags anything pending.
</Callout>

## Secret vs. plain

- **Secret** values are masked in the dashboard; revealing them is limited to
  owners.
- **Plain** values are shown in full — use these for non-sensitive config.

## Deleting

Deleting a variable removes it from the next deploy; it stays live on the running
container until then.
