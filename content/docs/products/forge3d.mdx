**Forge3D** is a 3D creation studio that runs in the browser. It covers the
pipeline end to end — model, texture, rig, simulate, and render — with an AI
assistant that can drive the tools for you.

## Tools

- **Model** — poly modeling, sculpt, retopology, and boolean operations.
- **Materials** — layered PBR materials baked into real texture maps.
- **Rig & animate** — an in-house auto-rigger plus animation editing.
- **Simulate** — cloth and hair, with GPU-accelerated solvers.
- **Scenes & render** — compose scenes, set up passes, and render stills or video.
- **Ask Forge AI** — an agent that can operate the studio through a registry of
  callable ops.

## Spaces

**Forge3D Spaces** is the architectural building studio built on the same engine
— design buildings and export them into the Forge3D pipeline. It's live at
[spaces.forge3d.ai](https://spaces.forge3d.ai).
